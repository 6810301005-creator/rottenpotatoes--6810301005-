## dependency ที่ได้จาก spring-boot-starter-test
| library | มีไว้ทำอะไร |
|---|---|
| junit-jupiter | เขียนและรัน unit test ด้วย @Test |
| assertj-core | เขียน assertion สำหรับตรวจผลลัพธ์ที่อ่านง่าย เช่น assertThat() |
| mockito-core | สร้าง test double / mock object เพื่อแยกส่วนทดสอบ |
| spring-boot-test | โหลดบริบทและเครื่องมือทดสอบของ Spring Boot |
